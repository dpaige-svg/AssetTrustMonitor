## Set Up:
This is a one click and ship application.

**Step 1:** Go to the launchers folder and run your Operating System's launcher file. ex: macOS or Windows
**Step 2:** Nothing!

## Here is why:
It sets up the environment and ensures it’s running from the project’s root directory.
It checks for Python 3. If not found, it tries to install Python automatically.
It sets up a virtual environment in app\Virtual Enviroment (creating it if needed).
It ensures pip is available in the virtual environment.
It installs all required dependencies from app\App_Build\requirements.txt.
Finally, it launches the main application (main.py) using the virtual environment’s Python.

## Why is this so beneficial?
This solved a problem with our current and at the time future workflow. 
The problem was that there was too many steps and not enough production.
This software features a sleek and modern design while giving the user a powerful and easy self healing tool that requires no knowledge of the systems it uses with all the perks of having it.
