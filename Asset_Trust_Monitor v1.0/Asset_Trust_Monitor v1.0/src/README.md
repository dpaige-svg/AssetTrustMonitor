# Asset Trust Monitor Source Code

This folder contains all the modular components of the Asset Trust Monitor application.

## Files:
- `config.py` - Configuration management
- `utils.py` - Utility functions  
- `rokit_manager.py` - Rokit & tool management
- `rojo_server.py` - Rojo server operations
- `file_monitor.py` - File monitoring & processing
- `ui_manager.py` - GUI components & styling
- `system_tray.py` - System tray functionality

## Usage:
Run `main.py` from the parent directory to start the application.
